# SentinelAI

SentinelAI is a beginner-friendly AI-powered cybersecurity assistant project.

The goal of this project is to learn:
- Cybersecurity
- AI integration
- Python
- APIs
- System design
- Automation

This project is part of a long-term hands-on learning journey into cybersecurity and AI engineering.

## Future Features
- Threat analysis
- Phishing detection
- Security learning assistant
